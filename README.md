## 🚀 About Me

I'm an Aerospace Engineering student interested in astronautics, spacecraft systems, avionics, embedded systems, and engineering test and integration.

My background includes high-powered student rocketry, a Python-based Raspberry Pi flight computer, embedded electronics, and production software infrastructure. I enjoy building systems that combine hardware and software, then testing and debugging them until they work reliably.
